# Sumaya Showcase

## Over het project

Dit project is mijn persoonlijke showcase website. De website is gemaakt om mijn werk, vaardigheden en projecten als UX/UI Designer en Frontend Developer te presenteren.

**Live website:**
https://sumayashowcase.netlify.app

## Gebruikte technologieën

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Netlify

## Functionaliteiten

* Geanimeerd laadscherm
* Overgang van Arabische naar Latijnse naamweergave
* Responsive design voor desktop en mobiel
* Project showcase sectie
* Interactieve hover-effecten
* Contactsectie

## Status van het project

Deze website is momenteel nog in ontwikkeling.

Geplande verbeteringen:

* Toevoegen van afzonderlijke projectpagina's
* Toevoegen van een About Me pagina
* Uitwerken van uitgebreide case studies
* Extra animaties en interacties
* Verdere visuele verbeteringen
* Optimalisatie van content en gebruikerservaring
